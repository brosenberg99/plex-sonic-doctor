Plex Sonic Doctor
Welcome. First, connect to your Plex server.

Scan

Scanning only reads your library. The first scan fingerprints the candidate files, which can take about an hour over a network share; later scans only check new or changed files.


      

      

        Optional: full damage check (slow)
        
Decodes every file looking for corruption. It takes hours for a big library, saves as it goes,
          and can be stopped and resumed. Afterwards, use Quick re-sort to add what it found to Possibly broken.

Files across the whole library that look damaged or wrong, for replacing. Broken files decode
      to garbage, won't open, stop early, aren't audio at all or are still encrypted. Likely broken covers songs that measure as pure silence, and albums
      where every track is the same clip. Check covers constant noise (often real noise music), intentional
      silence and missing files.

    

      

    
For replacing broken files an album at a time, for example by downloading iTunes
      purchases again. After replacing an album's files, press Recheck: every audio file in its folder is played
      all the way through, so you know straight away whether the new download worked, without waiting for Plex. A file
      that plays leaves the broken counts (and loses a Remove mark, so it isn't moved by mistake). In a
      folder of more than 200 loose tracks, only its broken files and any new ones are played.

Pairs whose audio only partly matches: alternate takes, remixes, variants, or the same song
      with a different intro. They aren't treated as copies. Listen if you're curious.

    

    

    

    

  


  
  

    
Tracks without Plex's sonic analysis can't be compared, so they never show up as copies. Plex
      analyses a whole album at once: if one file in an album won't decode, Plex skips the entire album, every
      night, without saying which file. This list names that file. Move the problem files out (or replace them) and
      the rest of the album gets analysed during Plex's next nightly maintenance.

    
Some tracks are marked analysed by Plex but have no sound profile: Plex threw the result away,
      which happens mostly with clips under 30 seconds. They're counted here, and there's nothing to fix.

    

    

      
      
    

    

      

    

    

  


  
  

    
Tracks whose tags (artist, album, title) are missing or wrong, and what they really are according to

      This tab never changes your files: fix the tags in

Identify tracks

      
Looking tracks up needs a free AcoustID key:
        get one here (sign in, then
        register an application with any name), and paste it in .

      
For each track, its audio fingerprint (the first two minutes, as numbers) and its length are sent to
        AcoustID, about 3 a second. No file names, paths or tags are sent. Tracks without a fingerprint are
        fingerprinted first. Each file is looked up once; it can be stopped and resumed.

      

        
        
        

      
Fixing tags in Picard without upsetting Plex
        
    
          
  • In Picard's Options › File Naming, turn off Rename files and Move files. Files then stay
            where they are, so Plex keeps their play counts, ratings and playlist places, and this app's move history
            stays right.
    • 
          
  • Open a folder in Picard, select the files and press Scan (AcoustID) or Lookup, check the
            album it found, then Save.
    • 
          
  • Plex picks up the new tags at its next library scan (or Move & undo › Ask Plex to rescan).
            Saving tags changes the files, so they're fingerprinted again at the next identify or scan.
    • 
        

    

    

    

      

    

      
      
      
    

    

    

    

  


  
  

    

      
Move the copies marked for removal

      
Marked copies are moved (never deleted) to the holding folder, keeping their folder layout,
        so every move can be undone. Every song keeps at least one copy; groups where everything is marked are skipped.

      
      

      

    

    

      
Moved batches

      

      

      
Plex marks moved tracks unavailable after a rescan. When you're happy, you can delete the
        holding folder yourself. Until then, everything can be put back.

    

  


  
  

    

      
What counts as an identical copy

      
A copy is identical to the keeper only if it passes all of these checks. Anything else that
        matches the song is a different version. After changing these, use Quick re-sort.
